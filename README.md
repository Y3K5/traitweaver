# Traitweaver

From a desired biological capability to a traceable study-preparation package.

A researcher defines an outcome and context. Traitweaver compares research proposals, maps evidence and weak assumptions, performs qualified local analyses, and prepares specific experiments with result-dependent next steps.

## Current status

This is the initial event-entry planning scaffold. It contains preparation documents and folder markers only; no application code, UI, model connection or biological result is included. The earlier local implementation remains separate prior work.

Start with [the mission](docs/MISSION.md), [contribution record](docs/CONTRIBUTIONS.md), [trait-library specification](docs/TRAIT_LIBRARY_SPEC.md), and [initial task proposal](tasks/01_STUDY_LIBRARY.md). The initial task is retained as planning history; subsequent coding tasks require separate review before implementation or publication.

## Development workflow

Muse Code authors approved local source. Codex and the owner review and verify it. Git records approved changes; the owner performs every push to the existing Traitweaver GitHub repository. Until an exact public review is complete, these files are candidates rather than publication approval.

Credentials, private research, raw conversations and local runs stay outside the project. Ignore rules are a secondary guard, not proof of safe publication. No UI is planned for the first implementation.
