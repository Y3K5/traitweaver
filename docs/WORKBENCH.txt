YOUR NOTES AND HISTORY
Expand Your notes & earlier versions to edit your review question/notes or inspect
earlier saved versions. These are uninterpreted annotations to a fixed starter
case. They cannot change original study evidence/objectives, model inputs or tool
arguments. Original study goal/constraint editing remains in its owning views.
Each save creates an immutable successor with source/parent/selected-base hashes;
maximum 32 revisions per case. Reopening cannot edit or rerun an imported record.
Notes are held in server memory; refresh preserves them while that process runs.
Export before shutdown. Unsaved browser drafts are not durable.

PRIVACY BEFORE EXPORT
Save/reset the current draft. Expand Review all saved notes in
Save for review. The server scans ALL included versions, not just selected/current
notes. Suspected personal paths, credential-shaped text/assignments, cookies,
active embeds, sensitive URL parameters or explicit private markings block both
JSON/Markdown, even direct endpoint attempts. Findings contain category, revision
and field only; no matched values. Nothing is silently scrubbed or removed.
A clean successor or selecting an old clean note does not remove an earlier
finding. There is no bypass or automatic history deletion. Keep a blocked case
local for owner review; a fresh session is not a scrubbed original history.
Even clean exports require acknowledgment bound to the current saved view. The
scan cannot identify all personal names/private prose. Privacy acknowledgment
is not scientific approval or permission to publish; human_review stays
not_reviewed. JSON preserves exact strings; Markdown safely encodes markup.

WHAT A WORKBENCH PACKAGE INCLUDES
All of the active case's notes, qualified case snapshot, accepted assistant
record and actual local audit receipts if present, plus available algae story.
It does not bundle other case slots, original study history, separate intelligence
journals or real Muse-cycle usage. Those keep their existing exports/pickers and
contracts. Workbench annotations never enter their original-schema exports.

REOPEN
Use Open a saved review (JSON) in Save for review, at most 512 KiB. Source pins,
history links, accepted records, receipts and checksum validate before the view
changes. Corrupt/stale/oversized input preserves the last valid view. Imported
workbenches are read-only; navigation/unsent public request preparation are safe,
annotation edits and tool/synthetic execution are blocked. Return to this local
case restores the separate local history. Reopening needs no model/tool rerun.
All included notes remain inspectable in the full-history export panel.
