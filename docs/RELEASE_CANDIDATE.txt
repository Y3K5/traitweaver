Open the printed loopback address. Choose Finish & review study in the menu.
This uses a visibly synthetic replay, pinned public evidence and no private files.
Python 3.10+ standard library only; no installation or API key required.

MAIN JOURNEY
1. Research journey: question -> cited evidence -> decision -> local-check result
   -> reassessment. With --demo these are synthetic replay records. Only an
   explicitly loaded, validated non-synthetic existing cycle represents saved
   real Muse work; neither mode runs a new model call.
2. Finish & review study: inspect the trait/source/mechanism/gene/transcript/
   protein/reference/recipient graph and four separate phosphorus endpoints.
3. Consider combined traits: source-bound starter proposals plus optional
   researcher hypotheses. All pairwise interactions remain unassessed; no score.
4. Review existing guide RNA / primer DNA / genomic DNA / protein records.
   Load the metadata-only example to learn the format. It has no sequence or
   biological target. Existing reports retain their original source, tool/version,
   reference, assessments and limits. No sequence is generated or made ready.
5. Shape the study: hypothesis, comparisons, readouts, confounders, containment,
   success/failure questions and missing decisions. No executable protocol.
6. Record a human judgment and reason for the exact saved content. This is a
   self-reported identity and judgment, not authentication or scientific proof.
   Changed content makes earlier reviews inapplicable without deleting them.
7. Review every included record/history, acknowledge LOCAL export, then download
   JSON and the readable brief. Reopen JSON through its picker or pasted text.
   Validation happens before replacing the view; reopening runs no tool/model.
   Return to original local review retains the previous editable session.

STORAGE
This new review owns a separate session-memory history, maximum 64 revisions,
8 trait proposals, 20 imported records and a 2 MiB package. Export before stopping
Python. Browser refresh preserves saved server-memory history while Python runs.
Unsaved form drafts survive step navigation and block export/reopen until saved
or explicitly discarded; leaving the page warns. Process termination before
export loses this session. Existing durable studies retain their own storage.
The review package includes sources, source identities, reference map, study
outline, imported values/settings/unknowns, blockers, review history and a loaded
cycle if present. It does not merge unrelated project files or other workbenches.
