# Mission

Build a headless study-preparation workbench for benign computational biology research.

Reason backward: desired outcome → claims → mechanisms/dependencies → evidence gaps → discriminating experiments.

Assemble support bottom to top: source/molecular identity where relevant → properties → function/pathways → context compatibility → phenotype hypotheses → proposed study. Preserve unestablished links; not every study needs protein modeling.

## Product slices

1. A small source-backed library of known trait/intervention/species examples, preserving endogenous edits, heterologous insertions, expression changes and natural-function reference cases as distinct classes.
2. Study records connecting a defined question, baseline, endpoints/units, competing proposals and explicit unknowns.
3. Source-qualified evidence and relevant local Biohub protein-record imports, with prediction/observation distinctions.
4. Qualified local analyses and versioned result/assessment receipts.
5. Experiment cards with claim traces, controls/readouts, independent units, assumptions, unknown thresholds and predeclared conditional branches.
6. Local JSON and readable study-package export, including unresolved researcher decisions and actual execution state.

Start with a narrowly defined public algae nutrient-recovery case only after source qualification. Phosphate uptake, phosphorus in biomass and recovered-product phosphorus are separate endpoints. Add a molecular question only if it informs a decision.

No UI, broad model installation, universal phenotype prediction, CRISPR guides, constructs, executable wet-lab protocols or environmental deployment. The product hands a researcher a reviewable study, not a biological success certificate.
